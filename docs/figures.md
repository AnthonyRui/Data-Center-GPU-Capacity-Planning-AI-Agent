# Figure guide / 图表说明

All figures are regenerated by `python run_analysis.py`. / 所有图表由分析入口重新生成。

Two English variants of the scenario comparison and PUE/GPU chart are saved in `figures/readme_en/` for the English README. / 场景对比及PUE/GPU图另存两份英文版本于`figures/readme_en/`，供英文README使用。

| File / 文件 | Interpretation / 解释 |
| --- | --- |
| `rack_power_breakdown.png` | Baseline server system power plus external network, kW/rack. / 基准服务器系统及外部网络构成，单位kW/机架。 |
| `pod_power_scaling.png` | IT and facility MW as rack count changes with baseline rack power and PUE. / 固定基准机架功率与PUE，观察机架数变化后的IT及设施MW。 |
| `facility_capacity.png` | Whole-pod deployment demand against the facility limit. / 完整Pod部署需求与设施上限。 |
| `remaining_capacity.png` | Unused MW after packing the maximum whole pods in each scenario. / 各场景最大完整Pod部署后未使用的MW。 |
| `scenario_comparison.png` | Facility MW/pod, pod count and GPU count; non-baseline inputs are reconstructed assumptions. / 每Pod设施MW、Pod数及GPU数；非基准输入为重建假设。 |
| `pue_sensitivity.png` | Continuous IT budget and discrete whole-pod capacity vs PUE. / PUE对应的连续IT预算与离散完整Pod容量。 |
| `gpu_capacity_vs_pue.png` | GPU capacity vs sampled PUE; steps connect sampled values, not analytically exact transition locations. / GPU容量与采样PUE；阶梯连接采样值，不表示解析求得的准确跳变位置。 |
| `rack_density_sensitivity.png` | GPU count and unused MW vs servers/rack with fixed network power. / 网络功率固定时，每机架服务器数对GPU数及剩余MW的影响。 |
| `pod_size_sensitivity.png` | GPU count and unused MW vs racks/pod. / 每Pod机架数对GPU数及剩余MW的影响。 |

The baseline plots use the row named `Baseline` from the supplied parameter CSV. Chinese labels appear where a supported font is available; this guide provides Chinese explanations on all platforms.

基准图使用参数CSV中名为`Baseline`的行。有支持字体时显示中文标签；本说明在所有平台提供中文解释。
